# cita-manifest

Typed schema-1 persistence for Cita's global library registry and authoritative
shelf manifests. It provides deterministic registry serialization, stable shelf
validation, atomic source-snapshot mutations, deterministic BibTeX rendering,
and cross-process library/shelf locks.

This crate is published for reuse by the Cita workspace. Its public API is
unstable while the version is 0.x and may change between minor releases.
