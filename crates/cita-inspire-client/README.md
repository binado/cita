# cita-inspire-client

An INSPIRE literature client for [cita](https://github.com/binado/cita), with a
slim public `ApiLiteratureRecord` JSON model, authoritative `InspireSnapshot`
BibTeX snapshots, bounded refresh batches, and rate-limit retries.

This crate is published for reuse by the cita workspace. Its public API is
unstable while the version is 0.x and may change between minor releases.
